# Data Lake with MinIO and DuckDB

## Requirements
```
boto3==1.34.34
pandas==2.1.4
duckdb==0.9.2
```

## Installation
```bash
pip install boto3 pandas duckdb
```

## Usage

### 1. Upload CSV data to MinIO
```bash
python upload_csv_data.py
```

### 2. Query CSV data using DuckDB
```bash
python query_csv_duckdb.py
```

### 3. Access MinIO Console
- URL: http://localhost:9001
- Username: minio
- Password: minio123

### 4. MinIO API Endpoint
- URL: http://localhost:9000
- Access Key: minio
- Secret Key: minio123

## Architecture
```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   Python App    │    │     DuckDB      │    │      MinIO      │
│                 │────│                 │────│   (3 replicas)  │
│ - Upload CSV    │    │ - Query CSV     │    │ - Object Store  │
│ - Data Analysis │    │ - Analytics     │    │ - S3 Compatible │
└─────────────────┘    └─────────────────┘    └─────────────────┘
```

## Features
- ✅ MinIO cluster with 3 replicas on Kubernetes
- ✅ S3-compatible object storage
- ✅ CSV data upload and management
- ✅ DuckDB integration for fast analytics
- ✅ Sample data and queries
- ✅ View creation and advanced SQL operations
